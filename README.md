# You can Sing! — Halyard stack

Browser karaoke + text-to-singing draft tool on a Kelly–Lochbaum tube model.
No third-party voice cloning. Consent-first studio remains at `/studio`.

## Routes

| Path | Feature |
|------|---------|
| `/` | **You can Sing!** karaoke — Daisy Bell, synced lyrics, score, tract viz |
| `/sing` | Same karaoke (alias) |
| `/write` | **Write → Sing** — paste lyrics → G2P → auto-melody → tube render → WAV / project JSON |
| `/studio` | Halyard consent-first voice job desk |

## Key modules

- `src/lib/tube-singer/` — vowels, Daisy Bell score, KL tract renderer, WAV export
- `src/lib/text-to-sing/` — G2P dictionary + fallback, auto-melody, project JSON
- `src/components/tube-singer.tsx` — karaoke UI
- `src/components/text-to-sing.tsx` — text-to-sing editor
- `src/components/studio.tsx` — consent studio

## Stack

TanStack Start / Router, Vite, React, Tailwind v4. Same App Builder / Halyard scaffold.

```bash
npm install
npm run dev   # typically host 0.0.0.0:8080 in App Builder
```

## Product limits (intentional)

- Physical model only on karaoke / text-to-sing paths
- Auto-melody is a **draft**, not a finished master
- No clone-a-famous-singer path; live SVC is out of band (see prior deployment notes)
